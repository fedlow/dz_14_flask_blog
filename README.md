# 🚀 Дневник программиста

Учебное веб-приложение-блог на микрофреймворке **Flask**, созданное в рамках выполнения домашнего задания. 
В проекте реализованы маршрутизация, наследование шаблонов Jinja2, работа с формами и стилизация.

## 📝 Описание проекта
Приложение состоит из двух страниц:
1. **Главная страница** — содержит информацию об авторе и таблицу успеваемости по дисциплинам (обновлена до 3-й темы).
2. **Дневник программиста** — страница с формой для добавления новых записей. Записи сохраняются в словарь (в оперативной памяти) и сразу отображаются на странице.

## 🛠️ Технологии
* **Python 3**
* **Flask** (микрофреймворк)
* **HTML5**
* **CSS3**
* **Jinja2** (шаблонизатор: наследование `extends`, блоки `block`, циклы `for`, условия `if`)

## 📂 Структура проекта

dz_13_flask_blog/

🚀 Как запустить проект локально

Убедитесь, что у вас установлен Python (версия 3.7 или выше).

Клонируйте репозиторий:

git clone https://github.com/ВАШ_ЛОГИН/dz_13_flask_blog.git

cd dz_13_flask_blog

Установите Flask:

pip install flask

Запустите приложение:

python app.py

Откройте браузер и перейдите по адресу: http://127.0.0.1:5000
